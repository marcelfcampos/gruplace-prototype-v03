# gruplace (protótipo)

Protótipo estático em HTML, CSS e JavaScript puros. Não precisa de build.

## Estrutura
- `index.html` e telas `2-` a `11-`: páginas do app
- `css/shared`, `css/pages`: estilos globais e por tela
- `js/shared`: módulos de dados (favoritos, seguir, interesses) em localStorage
- `js/pages`: scripts por tela
- `assets/img`: logos e imagens

## Rodar localmente
Abra `index.html` ou use um servidor estático (`npx serve .`).

## Deploy
Vercel: framework "Other", sem build command, raiz do repositório.
